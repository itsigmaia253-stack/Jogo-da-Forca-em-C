# Jogo-da-Forca-em-C
Jogo da Forca desenvolvido na linguagem C, com o objetivo de aplicar e aprimorar conhecimentos em lógica de programação, estruturas condicionais, laços de repetição, vetores, strings e funções. O jogo permite que o usuário tente descobrir uma palavra secreta por meio de tentativas de letras, respeitando um limite de erros.
